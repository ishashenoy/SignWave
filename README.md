# SignWave

SignWave is an interactive hand-pose rhythm game and rehab/training toolkit that uses MediaPipe hand landmarks, a small PyTorch pose classifier, and OpenCV/Flask front-ends to provide two modes:

- Local real-time game (OpenCV window) — run from the command line.
- Web dashboard + streaming (Flask) — run a web server to view sessions, calibration, and export results.

The project also includes tools for collecting landmark data, training the pose classifier, and exporting session metrics for rehab or practice tracking.

---

## Key Features

- Real-time hand-pose detection using MediaPipe's Hand Landmarker.
- Lightweight PyTorch `PoseNet` classifier (5 poses: `palm`, `1`, `2`, `3`, `fist`).
- Two user-facing entry points:
  - Local game using the webcam: `app.py`
  - Browser-based dashboard and streaming: `app1.py`
- Dataset capture helpers (`collect.py`) and training script (`train.py`).
- Session persistence and analytics via `database.py` (SQLite-backed helper).

---

## Repository Layout (high level)

- `app.py` — OpenCV-based local game (camera feed, model inference, gameplay loop).
- `app1.py` — Flask web server providing a streaming UI, dashboard, and session export.
- `collect.py` — Utility to capture labeled landmark CSVs into `dataset/`.
- `train.py` — Loads `dataset/*.csv`, augments, trains `PoseNet`, and writes `pose_model.pt`.
- `pose_model.pt` — Trained PyTorch model (generated by `train.py`).
- `hand_landmarker.task` — MediaPipe Hand Landmarker asset used by the apps.
- `assets/poses/` — PNG icons used for lanes/notes.
- `dataset/` — Example CSVs and captured landmark data for training.
- `templates/` and `static/` — Flask HTML templates and static assets for the web UI.

## Requirements

- Python 3.10+ recommended.

- This repo includes `requirements.txt`; install via pip as shown below.

## Quick Setup

1. Create and activate a virtual environment (Windows example):

```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. Confirm required model assets exist in the project root:

- `hand_landmarker.task` (MediaPipe asset)
- `pose_model.pt` (trained PyTorch weights)

If you don't have `pose_model.pt` you can train one with `train.py` (see below).

---

## Running

1. Local webcam game (OpenCV GUI):

```powershell
python app.py
```

This opens a native OpenCV window and runs the rhythm game using your webcam. Close the window or press the configured exit key to stop.

2. Web dashboard / streaming UI (Flask):

```powershell
python app1.py
```

Open your browser at http://localhost:5000 to view the dashboard, calibrate poses, start songs, and export session CSVs.

Notes:
- `app1.py` starts a Flask server with templates in `templates/` (e.g., `calibrate.html`, `dashboard.html`, `results.html`).
- The Flask app also exposes helpful API endpoints (e.g., `/api/progress`, `/api/ideal_poses`) used by the UI.

---

## Data Collection and Training

1. Capture landmarks:

- Use `collect.py` to capture hand landmarks into CSV files under `dataset/`. The CSV format expected by `train.py` is 42 numeric columns (21 x/y pairs) followed by a label column.

2. Train the classifier:

```powershell
python train.py
```

- `train.py` concatenates `dataset/*.csv`, normalizes landmarks (wrist-normalized), augments (mirroring and jitter), and trains the `PoseNet` MLP. The script saves `pose_model.pt` to the repo root when complete.
- Default training runs for 500 epochs; see `train.py` for hyperparameter edits.

---

## Calibration / Ideal Poses

- The web UI contains a calibration flow (`calibrate.html`) that stores ideal poses in the database. Capture clear examples for each pose to improve scoring and joint-deviation analytics.

---

## Database & Exports

- `database.py` contains helpers to persist sessions, notes, and averaged joint deviations (SQLite). The Flask UI exposes an export feature (`/export/<session_id>`) to download a CSV summary for a session.

---

## Troubleshooting

- Camera not found: ensure your webcam is available and not used by other apps. On Windows, check Privacy settings if the camera is blocked.
- MediaPipe model errors: ensure `hand_landmarker.task` is present and readable by the app.
- Audio issues (Flask uses `pygame` for tones): on Windows, you may need to install audio drivers or run the server from a user session with audio privileges.
- Slow inference: disable debug flags, or run on a machine with a GPU and update the PyTorch installation accordingly.

---

## Development Notes

- Change the pose set and labels consistently across `collect.py`, `train.py`, and the apps. Labels used by `train.py` are: `palm`, `1`, `2`, `3`, `fist`.
- To tweak gameplay (spawn interval, speed, hit zone), edit constants in `app.py` or `app1.py` like `SPAWN_INTERVAL`, `NOTE_SPEED`, and `HIT_ZONE_Y`.
